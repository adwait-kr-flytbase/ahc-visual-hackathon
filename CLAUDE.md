# AHC Visual Intelligence Hackathon — Real-Time Video Anomaly Detection

**Read `.context/README.md` first.** It is the index for this project's knowledge base and is
maintained across sessions and agents. Everything established so far lives there.

## Rules for `.context/`
- **It is the shared memory.** Any durable finding — a measured number, a resolved unknown, a
  decision and its reason, a dead end — gets written there, not left in chat.
- **Keep it clean.** Distilled findings only. No raw dumps, no transcripts, no speculation
  presented as fact. If a file stops being scannable, tighten it.
- **Mark provenance.** Distinguish *measured*, *read in a paper*, and *assumed*. Strike through
  or delete claims that are disproven — do not accumulate stale text.
- `.context/sources/` holds verbatim organiser docs. **Never edit those.**
- Open unknowns belong in `.context/README.md` under "Open questions", and move to
  `.context/06-decisions.md` once resolved.
